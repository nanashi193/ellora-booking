# Ellora Decisions Log

This directory contains records of important technical and design decisions made throughout the development of Ellora.

## Format

When logging a new decision, use the following format:

### YYYY-MM-DD - Decision title

**Context:**
[Describe the problem, situation, or background that led to this decision.]

**Decision:**
[Clearly state what the decision is.]

**Reason:**
[Explain why this decision was made. What were the trade-offs? Why is this the best option?]

**Impact:**
[Describe the consequences of this decision, including affected areas of the codebase, UX, or future development.]

# AI Agent Working Conventions for Ellora

These conventions must be followed by AI agents (Antigravity/Codex) when making changes to the Ellora project.

## General Rules
- **Context First:** Always read `docs/ai/context.md` before making any code modifications.
- **Focused Changes:** Prioritize small, clear changes. Do not rewrite large portions of unrelated files.
- **Summary Required:** After making changes, you must provide a summary of which files were modified and the reasons for those modifications.

## Code Conventions
- Maintain the existing coding style of the Ellora project.

## UI Conventions
- **Mobile-First Validation:** Always check responsive and mobile layouts first before desktop.
- **Aesthetic Alignment:** Keep the soft, modern, beauty-focused style with `#f7bcd5` for main CTAs.
- **Layout Caution:** Be particularly careful with sticky/fixed elements to prevent overlapping with other content.

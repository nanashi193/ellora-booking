# Ellora Project Context

## Product Overview
Ellora is a booking platform designed specifically for salons, spas, and beauty services.

## Target Users
- **Customers:** Booking beauty appointments and services.
- **Salon Owners/Managers:** Managing services, staff schedules, and customer appointments.

## Tech Stack

**Frontend:**
- **Framework:** Angular 21 (with `@angular/cdk`, SSR enabled)
- **Styling:** Tailwind CSS, PostCSS, Autoprefixer
- **Other Libraries:** AWS Amplify, Chart.js (`ng2-charts`), RxJS
- **Testing:** Vitest, JSDOM

**Backend:**
- **Language/Framework:** Java 17, Spring Boot 3.2.5
- **Database:** PostgreSQL (with Spring Data JPA)
- **Security:** Spring Security, OAuth2 Resource Server
- **Utilities:** MapStruct, Lombok
- **API Documentation:** Springdoc OpenAPI 3 (Swagger UI)

## Important UX Patterns
- **Mobile-First Frontend:** The user experience is optimized primarily for mobile devices.
- **Visual Style:** Soft, modern, and beauty-focused design.
- **Primary CTA:** The main Call to Action color is `#f7bcd5`.
- **Key UI Elements:**
  - Salon detail page
  - Sticky booking widget
  - Salon cards
  - Search and filter functionalities
  - Google Maps integration
